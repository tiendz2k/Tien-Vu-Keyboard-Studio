# Tien Vu Keyboard Studio — v3.11.1

Phần mềm điều khiển bàn phím cơ trên Windows: đèn RGB, màn hình TFT, macro, nhạc, màn hình chào và nhiều hãng phím (AULA, Akko, MonsGeek, MCHOSE, DareU, Leobog, YUNZII...).

## Cài đặt

1. Giải nén file zip vào một thư mục bất kỳ.
2. Chạy `TienKeyboardStudio.exe`.
3. Bản **Light** cần có sẵn **.NET 8 Desktop Runtime** (tải miễn phí từ Microsoft). Bản **Compressed** chạy ngay, không cần cài thêm gì.

## Bắt đầu nhanh

1. Cắm bàn phím bằng cáp **USB-C** (màn hình TFT và các tính năng ghi sâu chỉ chạy qua cáp).
2. Mở app, bấm **Quét bàn phím** ở trang Tổng quan.
3. Chọn đúng mẫu phím của bạn rồi vào từng trang tính năng ở thanh bên.

## Lưu ý an toàn

- App mặc định bật **Dry-run** (chế độ thử, không ghi thật xuống phím). Chỉ tắt Dry-run khi bạn chắc chắn muốn ghi thay đổi xuống bàn phím của mình.
- Các tính năng ghi nhãn "thử nghiệm" đang trong quá trình kiểm chứng — hãy dùng với phím của bạn một cách thận trọng.
